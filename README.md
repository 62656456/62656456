## Current focus

- Script and directing intelligence
- Character, scene, and prop continuity
- Executable camera plans instead of decorative shot language
- AI-video production and playback review
- Cross-Agent Skill portability and evidence-aware validation

## Evidence boundary

Repository structure, tests, packaging, real outputs, and user acceptance are recorded as separate states. A passing validator is not presented as proof of creative quality or final user approval.
